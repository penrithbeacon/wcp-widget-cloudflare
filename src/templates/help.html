About this widget

The Cloudflare WCP widget gives you a quick view of your Cloudflare account inside Penrith Beacon WCP Dashboard. It calls the Cloudflare API directly using your own API token — no data passes through any third party.

The widget exposes four components, each sized at 12 × 6 by default. That's a full stave in standard Penrith Beacon WCP layout. The intent is that you create a dedicated "Cloudflare" orchestration with four staves — one per component — and use the Orchestration Manager to switch to it when you want to manage Cloudflare. You can complement those staves with link cards, snippets, or other widgets that fit your Cloudflare workflow.

Components

Workers
List your Workers with their domains. Open Site / Open Repo buttons.
Domains + DNS
All your zones in a left pane. Click a domain to see its DNS records in the right pane.
Settings
Edit your API token, Account ID, and Worker → repo URL mappings without leaving the dashboard.

Setup Guide

You need two pieces of information from Cloudflare:

1. Find your Account ID

  1. Log in to the Cloudflare dashboard
  2. Pick any domain (or go to the Workers & Pages section)
  3. Look at the right-hand sidebar — your Account ID is a 32-character hex string
  4. Click the copy icon next to it

2. Create an API Token

  1. Go to My Profile → API Tokens
  2. Click Create Token
  3. Use the Custom token template (most flexible)
  4. Add these permissions:
    • Zone → Zone → Read
    • Zone → DNS → Read
    • Account → Workers Scripts → Read
    • Account → Worker Routes → Read (for domains list)
  5. Set Account Resources to your account, Zone Resources to All zones
  6. Click Continue to summary → Create Token
  7. Copy the token immediately — Cloudflare only shows it once

3. Configure the widget

Open the Settings component (one of the four components in this widget) and paste both values in. Click Save Settings. The Workers and Domains components should now show your live data.

Tip. The Account ID and API Token can also be set when you first add this widget to a stave — the dashboard's standard widget configuration form picks them up automatically. The Settings component is for editing them later or for adding Worker → repo mappings.

FAQ

Where is the data stored?

All credentials and worker→repo mappings live in /app/data/config.json inside this container's named Docker volume. They never leave your machine except in API calls direct to Cloudflare.

How fresh is the data?

Workers and DNS results are cached for 30 seconds; zones for 120 seconds. Click the Refresh button to bypass the cache.

Can I add a widget that's already on Cloudflare's UI but missing here?

Open an issue at the project repository (see About below). The widget intentionally focuses on Workers + Domains + DNS — the three things most often glanced at — but more components can be added as needs emerge.

What if my API token leaks?

Revoke it immediately from My Profile → API Tokens, generate a new one, paste it into the Settings component.
